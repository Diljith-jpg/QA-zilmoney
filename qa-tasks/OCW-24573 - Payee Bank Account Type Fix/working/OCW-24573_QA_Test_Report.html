Task Overview

This backend sub-task fixes the bank account type for bank accounts linked through Plaid. Previously, the account type came through as a number (for example 1) instead of an account type name. QA linked bank accounts through Plaid in both the new and the classic design. The bank account type now fills in automatically from the Plaid account selected: a Plaid checking account becomes Business Checking, and a Plaid savings account becomes Personal Savings. The fix works as expected.

Issue / Requirement Description

  • When a bank account was added through Plaid, the bank account type was fetched as a numeric value (for example 1) instead of the correct account type.
  • Requirement: the account type of the Plaid account selected must map to the correct bank account type automatically.

Updates / Changes Implemented

  • The backend maps the Plaid account type to the bank account type: Plaid checking → Business Checking, Plaid savings → Personal Savings.
  • The bank account type now appears as the correct name, not as a numeric value.

Testing & Verification

New design

  • Verified that adding a bank account through Plaid with a checking account sets the account type to Business Checking.
  • Verified that adding a bank account through Plaid with a savings account sets the account type to Personal Savings.

Classic design

  • Verified that a Plaid checking account sets the account type to Business Checking.
  • Verified that a Plaid savings account sets the account type to Personal Savings.
