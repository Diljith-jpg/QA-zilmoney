Task Overview

The task fixes the Bulk Payment table, where the Payment Count and Total Amount did not follow the applied filters and showed values from the unfiltered data. QA tested the My Groups table in the V4 Bulk Payment Center on staging. Each filter was applied on its own, then both together, then with a value that matches nothing, and finally cleared. Every filter returned only matching records, and the result count and amounts on screen matched the filtered rows. The fix works as expected.

Issue / Requirement Description

  • Reported: after a filter was applied on the Bulk Payment table, Payment Count and Total Amount stayed the same and kept showing values based on the unfiltered data (P2, affects data accuracy).
  • Requirement: applying a filter updates the displayed Payment Count and Total Amount.
  • Requirement: the Payment Count matches the number of visible records after filtering, and the Total Amount matches the values of the visible records.

Updates / Changes Implemented

  • The Payments Count column filter now returns only groups with the entered payment count.
  • The Total Amount column filter now returns only groups with the entered total amount.
  • The two filters work together, and the result footer ("Showing X to Y of Z results") updates to match the filtered list.

Testing & Verification

Payments Count filter

  • Confirmed that the unfiltered table shows 43 groups ("Showing 1 to 43 of 43 results").
  • Verified that filtering Payments Count by 2 returned 15 results, and every visible row had a Payments Count of 2.
  • Confirmed that clearing the filter brought back all 43 groups.

Total Amount filter

  • Verified that filtering Total Amount by 150 returned 5 results, and every visible row showed $150.00.
  • Verified that a value that matches nothing (987654) showed "No results found" and "Showing 0 results" without errors.

Combined filters and stability

  • Verified that Payments Count 3 together with Total Amount 150 returned only the 2 groups that match both (3 payments / $150.00).
  • Confirmed that clearing all filters brought back the full list of 43 groups.
  • Confirmed that no application console errors were logged while filtering.
