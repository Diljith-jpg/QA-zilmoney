Task Overview

The task fixes the bank account Audit Trail, where the IP address was missing and the date wrapped awkwardly. The updated build was tested in both V3 and V4 on 10 bank accounts. For every entry, the By, IP Address, Device and Notes values in the table were compared with the activities API response. All entries matched in both versions, the IP address is present on every entry, and device names appear wherever the API provides one. The two-line date/time layout (date with the time below it) was confirmed as the intended design and accepted.

Issue / Requirement Description

  • Reported: the Date value wrapped onto a second line due to insufficient column space, and the IP address was not displayed in the audit log.
  • Requirement: display the IP address for each applicable audit log entry.
  • Requirement: other audit log columns must keep their alignment and readability.
  • Date layout: the ticket asked for a single line. QA was told the stacked date/time layout is the intended design and should not be failed.

Updates / Changes Implemented

  • The Audit Trail now has separate IP Address and Device columns (Date, Status, By, IP Address, Device, Notes) in V3 and V4.
  • The date cell shows the date with a smaller, grey time below it, and neither line wraps.
  • The By column is set to no-wrap.

Conclusion

The Bank Account Audit Trail now shows the IP address and the device correctly in both V3 and V4. On 10 accounts, every entry matched the activities API, and recent entries show both values. The Status, By and Notes columns are unaffected, and no console errors appeared. Older entries without a device name show a blank Device cell because the API returns no device for them. That is existing data, not a defect in this build. Responsive widths could not be checked in this run, because the browser tool cannot change the page viewport.
