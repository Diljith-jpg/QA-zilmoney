Task Overview

During transaction verification, reviewers open the SEON AML Analysis screen through "SEON Status". Before this change, the AML Screening section under Payer Information had to be expanded to see the result. The task shows the screening result on the screen by default. QA checked each acceptance criterion: the default view, the No Matches and Matches Found outcomes, the match details, and the pending or unavailable state. All criteria were met. A QA test video is linked on the ticket.

Issue / Requirement Description

  • Reported: AML screening information was not visible right away. Reviewers had to expand the AML Screening section under Payer Information, which added clicks.
  • Requirement: show the AML screening status by default when the SEON AML Analysis screen opens.
  • Requirement: clearly show "Matches Found" or "No Matches", based on the screening response.
  • Requirement: when matches exist, show the relevant match information on the same screen without extra clicks.
  • Requirement: clearly identify pending or unavailable results, and never show them as "No Matches".

Updates / Changes Implemented

  • The SEON AML Analysis screen shows the AML screening result as soon as it opens. The section no longer needs to be expanded.
  • The result is labelled "Matches Found" or "No Matches", based on the screening response.
  • When there are matches, their details appear on the same screen.
  • Pending or unavailable screenings are labelled separately from "No Matches".

Testing & Verification

Default visibility

  • Verified that opening the SEON AML Analysis screen from "SEON Status" shows the AML screening result straight away, with nothing to expand.

Screening outcome

  • Verified that a transaction with no screening matches shows "No Matches".
  • Verified that a transaction with screening matches shows "Matches Found".
  • Confirmed that the match information for a transaction with matches is shown on the same screen without extra clicks.

Pending / unavailable results

  • Confirmed that a pending or unavailable screening is clearly identified as such and is not shown as "No Matches".

The SEON AML Analysis screen now shows the AML screening result by default. It clearly states Matches Found or No Matches, and it shows match details on the same screen without extra clicks. Pending or unavailable screenings are labelled clearly and are not reported as No Matches. All acceptance criteria of OCW-24805 are met on staging.
