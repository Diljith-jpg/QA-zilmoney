Task Overview

The task makes long payee names readable in the Payee filter dropdown on the Payments Out page. The dropdown was tested in Version 2.0 on the OCW-24777 build and compared side by side with the same page, company and payees on the current staging build. On the OCW-24777 build, a truncated payee name shows its full name in a tooltip on hover, short names show no tooltip, and the dropdown is wider and taller than on staging. Search, selecting, applying, clearing, scrolling, the Check and ACH tabs, and dark mode all worked.

Issue / Requirement Description

  • In the Payments Out table, long payee names in the Payee dropdown were cut off with "…" and no tooltip appeared on hover, so the full name could not be read.
  • Requirement: show the full payee name in the Payee dropdown (Jira description; confirmed by the QA lead as a hover tooltip plus a wider and taller dropdown).

Updates / Changes Implemented

  • Hovering a truncated payee name in the dropdown shows a tooltip with the full "Name (Nickname)" text. The tooltip appears only when the name is actually truncated.
  • Dropdown width increased from 240 px to 250 px; the visible text area per row went from 174 px to 184 px.
  • List height increased from 160 px to 190 px, so about one more payee is visible without scrolling.

Testing & Verification

Tooltip (Payments Out → All)

  • Verified that hovering "0969 Ocean View Road (0969 Ocean View Road)" and "01219 Plumbing Inc2 (01219 Plumbing Inc2)" shows the full name in a tooltip.
  • Verified that a short name ("11 PAY WEB2 (11 PAY WEB2)") shows no tooltip.
  • Confirmed that on staging the same names are cut off and no tooltip appears.

Dropdown size (compared with staging)

  • Verified that the dropdown is 250 px wide on the OCW-24777 build vs 240 px on staging.
  • Verified that the list area is 190 px tall on the OCW-24777 build vs 160 px on staging; row height is unchanged (34 px).

Dropdown behaviour

  • Verified that searching "Plumbing" narrows the list to the matching payee, and that the tooltip works on the search result.
  • Verified that selecting the payee and clicking Apply filters the table to that payee, and that the clear (×) control brings back the full list.
  • Verified that the list scrolls inside the taller area, that more payees load on scroll (10 → 20), and that the tooltip works on a payee that loaded later ("ABC Medical Records Inc (…)").
  • Confirmed that the page does not scroll sideways while the dropdown is open.

Other tabs and theme

  • Verified the same width (250 px), height (190 px) and tooltip on the Check and ACH tabs.
  • Verified that the dropdown and tooltip are readable in dark mode.
  • Confirmed that the app logged no console errors while these steps were run.

Observations

  • Not covered in this run: smaller window widths (the browser window could not be resized; it stayed at 1920 px) and the Wire, Virtual Card, Recurring and QuickBooks tabs.
  • The change applies to Version 2.0 only. In the old version (Payments table, V1), the Payee dropdown is unchanged and matches staging: names cut off, no tooltip. This is outside this ticket's scope as clarified.
  • Pre-existing, unrelated to this ticket: the V1 Payments page logs TypeError: Cannot read properties of undefined (reading 'x') on load.

Conclusion

On the Version 2.0 Payments Out page, long payee names in the Payee dropdown now show their full name in a tooltip on hover, short names show no tooltip, and the dropdown is wider (250 px vs 240 px) and taller (190 px vs 160 px list) than on staging. Search, filter, clear, scrolling, the Check and ACH tabs, and dark mode all work. Smaller window widths and the remaining payment tabs were not tested.
