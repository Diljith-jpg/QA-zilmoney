Task Overview

The task fixes the Partially Paid status filter on the Credit Memo page, which returned no results even though Partially Paid credit memos existed. Testing was carried out on staging in both the classic (V3) and new (V4) versions, using seven existing credit memos covering every status (two Partially Paid). In both versions the Partially Paid filter now returns exactly the two Partially Paid records, the other status filters return the correct records, the filter combines correctly with column search, and the empty-state message appears only when nothing matches.

Issue / Requirement Description

  • Selecting Partially Paid in the Status filter on the Credit Memo page showed no results, although matching records existed. The same issue was reported in V3.
  • Requirement: the Partially Paid filter must return all records with that status in V3 and V4; other status filters must keep working; the empty-state message must show only when no records match.

Updates / Changes Implemented

  • The Credit Memo Status filter now retrieves Partially Paid records correctly in V3 and V4.
  • Filter requests are served by the credit memo list and count endpoints, both returning 200 with no console errors.

Testing & Verification

Credit Memo — V3 (classic)

  • Verified that Status = All lists all 7 credit memos.
  • Verified that Status = Partially Paid lists only credit memos #2 and #522 (2 of 2 results).
  • Confirmed that New (3), Void (1) and Completed (1) return the correct records.
  • Confirmed that a status with no matching records shows "Sorry! No results found".

Credit Memo — V4 (new version)

  • Verified that Status = Partially Paid lists only credit memos #2 and #522 (2 of 2 results).
  • Confirmed that New (3), Void (1) and Completed (1) return the correct records.
  • Verified that Partially Paid combined with a Payee search returns only the matching record (#522).
  • Confirmed that clearing the status filter restores the full list for the remaining search.
  • Confirmed that a status with no matching records shows "No results found".

Observations

  • The Status dropdown (V3 and V4) includes "Mark as Completed", which reads as an action rather than a record status and returned no records. To be confirmed with development against the requirement that dropdown options match record statuses.
  • V3 footer on an empty result reads "Showing 1 to 0 of 0 results" (V4: "Showing 0 results"). Cosmetic.

Conclusion

The Partially Paid status filter on the Credit Memo page now returns the correct records in both V3 and V4 on staging, and the New, Void, Completed and All filters, combined column search and the empty state continue to work as expected. Credit Note and the Invoice list status filter were not covered in this run.
