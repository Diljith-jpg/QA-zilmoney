Task Overview

Customers reported that filtering Payments Out by Wallet and then Mailed did not list all mailed wallet checks, and that wallet checks did not keep a consistent number. The fix makes the Mailed filter return mailed records and fills the Reference ID field for mailed checks. Both filters were tested on the new Payments Out page and the Classic Payments page, for wallet and bank sources. Totals were reconciled against all 125 wallet Mail payments, and the Reference IDs were checked in the grid and detail views. Filtering works correctly in both UIs, and wallet checks mailed after the fix show their Reference ID. Two wallet checks mailed before the fix have no Reference ID; QA confirmed this is expected, because the change applies only to checks mailed after it.

Issue / Requirement Description

  • Filtering by Wallet then "Mailed" did not show all mailed checks issued from that wallet.
  • Wallet checks sometimes showed a different number from the one they were issued with.
  • Requirement: Wallet + Mailed lists every mailed wallet check; filtering works for both wallet and bank account checks; wallet checks consistently show their original number.
  • Dev note (from QA brief): when the status is Mailed, a reference ID is stored in the Reference ID field.

Updates / Changes Implemented

  • Payments Out → All: Source = WALLET with Status = Check › Mailed now returns the mailed wallet checks (old and new UI).
  • Mailed wallet checks show a Reference ID in the grid and in the new-UI detail panel (header "Ref: …" and Payment details).
  • Before the fix, the Reference ID was not stored for mailed checks. The change applies to checks mailed after it, and existing records are not backfilled (confirmed by QA).

Testing & Verification

Classic UI — Payments → All

Check tab — Mailed (both UIs)

Conclusion

Filtering by Wallet + Mailed and Bank + Mailed works correctly in both the new Payments Out page and the Classic Payments page. Every mailed record is returned, and the counts reconcile (3 wallet + 28 bank = 31 Mailed). Wallet checks mailed after the fix show their Reference ID in the grid and in the new-UI detail panel. Checks mailed before the fix keep a blank Reference ID, which is expected. No defects were found for this ticket.
