2. Objective

OCW-24304 implements the referral (affiliate) dashboard in the new version from the approved UX design in OCW-22810. The ticket carries a one-line description and no acceptance criteria, so the design state frames are the specification. QA will confirm that each state — empty, populated, payout request and confirmation, withdrawal history, share, commission structure, credit adjustment, coupon enabled and terms — matches the design in layout, content, typography and colour; that every control works; that the page reflows correctly at ≤785px and in dark theme; and that referral, coupon and payout data shown on the page agree with the backend. Anything that differs between the ticket, the design file and the build, or that the design leaves undefined is raised with the PM rather than resolved silently.

  • Typography — font family, size, weight and colour against the design (Funnel Display for titles and values, Funnel Sans for text).
  • Every button, link, tab, chip, toggle, sort and pagination control performs its action.

  • Values shown match the backend (earnings, balances, referrals, coupons, withdrawals).
  • Dark theme and the ≤785px reflow.

  • Classic version affiliate pages — regression check only.

5. Test approach

  • Design comparison: open each design frame (served locally) next to the build at 1536 × 840 and compare order, spacing, content and states.
  • Typography: read computed styles in DevTools for page title, stat labels/values, card titles, buttons, table headers and modal text, against the design values.
  • Functional: exercise every control once on an account with data and once on an account with no affiliate activity.
  • Data check: compare stat cards, tables and chart with the API response for the same account; compare with the existing (classic) affiliate page for the same account.
  • Payout: use a test account with an approved balance above $100 on staging; record the reference created. Approval and payment are not exercised.
  • Responsive: DevTools device toolbar at 1920, 1536, 1280, 1024, 785, 768 and 390px, plus a live resize across 785px.
  • Browsers: Chrome (primary), Edge, Firefox and Safari.
  • Test data: two companies — one with referrals, coupons, clicks and withdrawals; one never used as an affiliate — plus a second company for cross-company checks.

9. Entry and exit criteria

Entry criteria

  • OCW-24304 is dev-complete and deployed to the QA environment, with unit test evidence attached.
  • Test data available: an affiliate company with referrals, coupons, clicks, an approved balance above $100 and past withdrawals; a company with no affiliate activity; a second company for cross-company checks.

Exit criteria

  • All test cases and regression checks executed.
  • No open Critical or High defects; Medium/Low defects agreed with the PM for later fix.
  • Payout and coupon validation confirmed on the server, not only in the UI.
  • QA test report delivered with Status: QA Pass.
