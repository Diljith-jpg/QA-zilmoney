Task Overview

Users assumed the "Language" setting changes the application language, when it only controls the language of the check amount in words. The task asks for the field to be renamed, the English and French options to be kept, and an explanatory tooltip to be added. Both V3 and V4 General Settings were tested. The tooltip is in place in both versions and the options are unchanged, but the field label still reads "Language" in both versions, so the rename has not been implemented.

Issue / Requirement Description

  • Reported: the "Language" field (English / French) under Settings is confused with the application language. It only sets the language of the check amount in words.
  • Requirement: rename the field to "Check Amount-in-Words Language".
  • Requirement: keep the existing English and French options.
  • Requirement: add a tooltip. Suggested text: "Select the language used to write the check amount in words. This setting does not change the application language."

Updates / Changes Implemented

  • An info icon is added next to the field label in V3 and V4. Hovering it shows a tooltip to the right.
  • The field label is unchanged: it still reads "Language".

Testing & Verification

V4 (Version 2.0) — Settings → App Settings → General

  • Verified that hovering the info icon shows: "Select the language used to write the check amount in words. This setting does not change the application language". This matches the suggested text, except that the final full stop is missing.
  • Confirmed that the dropdown still lists English and French, and the saved value (English) is unchanged.
  • Observed that the field label reads "Language *", not "Check Amount-in-Words Language".
  • Confirmed that no console errors appeared.

V3 (classic) — Settings → Application Settings → General

  • Verified that the same tooltip appears on hovering the info icon, with the same text.
  • Confirmed that the dropdown still lists English and French, and the value is unchanged.
  • Observed that the field label reads "Language *".
  • Confirmed that no console errors appeared.

No settings were saved during testing: the dropdown was opened to check the options and closed without changing the value.
